An AI-powered web app that helps students and freshers prepare for interviews. It generates **personalized questions from resumes and job descriptions**, evaluates answers, gives AI-driven feedback, and tracks progress with a **performance dashboard** that highlights skill gaps and recommends topics to learn.

- **Tech Stack:** `Python` `Next.js` `React.js` `TypeScript` `Tailwind CSS` `FastAPI` `PostgreSQL` `LLM API` `Scikit-learn` `Pandas` `NumPy`
- 🔗 [View Code](https://github.com/Gani905911?tab=repositories)

- **Tech Stack:** `Python` `Pandas` `NumPy` `Scikit-learn` `XGBoost` `Matplotlib` `Seaborn` `Plotly` `Flask` `HTML` `CSS` `JavaScript` `MySQL`
